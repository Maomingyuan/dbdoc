# 系统架构

```
┌─────────────────────────────────────────────┐
│                  Vue 3 前端                  │
│  登录 / 数据源 / 表列表 / 表详情 / 搜索 / 导出  │
└──────────────────────┬──────────────────────┘
                       │ HTTP / JSON
┌──────────────────────▼──────────────────────┐
│              Spring Boot 后端                │
│  Controller / Service / Repository / Security │
├─────────────────────────────────────────────┤
│  数据源管理  │  元数据采集  │  快照 Diff  │ 导出 │
├─────────────────────────────────────────────┤
│  JDBC 驱动层：MySQL / PostgreSQL / ...       │
└──────────────────────┬──────────────────────┘
                       │
┌──────────────────────▼──────────────────────┐
│        元数据库（MySQL）  │  业务数据库        │
└─────────────────────────────────────────────┘
```

## 模块划分

| 模块       | 职责                                | 迭代    |
| :--------- | :---------------------------------- | :------ |
| 数据源管理 | 数据源 CRUD、连接测试、密码加密存储 | 第 2 周 |
| 元数据采集 | 通过 JDBC 采集表、字段、索引、主键  | 第 3 周 |
| 数据字典   | 表列表、表详情、全局搜索            | 第 4 周 |
| 导出       | Markdown / HTML 导出                | 第 5 周 |
| 快照 Diff  | 元数据快照与版本差异对比            | 第 6 周 |
| ER 图      | 外键解析与表关系可视化              | 第 7 周 |
| 权限审计   | 登录、角色、审计日志                | 第 8 周 |

## 技术选型说明

- **元数据库**：MySQL 8.0+，由 Flyway 管理版本
- **元数据采集**：直接基于 JDBC `DatabaseMetaData`，避免 ORM 对异构数据库的抽象损耗
- **ORM**：计划使用 MyBatis-Plus（第 2 周引入）
